# 本地备份文件保存与恢复

在设置的本地备份面板提供立即保存功能，用户通过系统文件对话框选择文件名和保存路径；可以选择保存的文件恢复当前配置。

## Requirements

- 支持手动保存主机、凭据、密钥、片段及当前本地备份支持的设置。
- 保存前显示系统保存对话框，取消操作不写文件。
- 不依赖云服务或 OAuth 配置；复用当前本机加密，产品明确提示用于本机恢复。
- 提供从文件恢复入口，先预览、确认，再通过现有保护性备份流程覆盖配置。
- 自选路径的文件不受自动备份保留份数清理。
- 覆盖中英繁体及已有语言的界面文案，保留原自动历史功能。

## Acceptance Criteria

- AC-1：保存对话框选择的路径生成可读回的加密 JSON；文件中不存在明文密码和私钥。
- AC-2：取消保存或取消打开文件不会写文件、覆盖数据或弹出成功提示。
- AC-3：可选导出文件并显示恢复确认；损坏、不支持格式、错误加密环境拒绝恢复。
- AC-4：恢复前调用现有保护性备份；没有云主密钥时仍可保存，恢复遵循现有主密钥门禁。
- AC-5：定向桥接和 UI 测试、lint、生产构建及 ARM64 打包通过；交付 fork PR 和可用安装版。
